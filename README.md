# Brian Mbithi | Portfolio

A single-page personal portfolio website showcasing my background, skills, and projects as an aspiring software engineer.

## Live Demo

[View live site](https://github.com/BrianMbithi1/BrianMbithi_portfolio.git) 
## Features

- Responsive single-page layout with a sticky header and section navigation (About, Skills, Projects, Contact)
- About Me section with a short bio and profile photo
- Skills list dynamically rendered from a JavaScript array
- Project cards dynamically rendered from a JavaScript array of objects
- Contact section with direct email and GitHub links
- Mobile-responsive design that adapts layout below 480px screen width

## Technologies Used

- HTML
- CSS (Flexbox, Grid, custom properties, media queries)
- JavaScript (DOM manipulation, array iteration)

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/BrianMbithi1/REPO-NAME.git
   ```
2. Navigate into the project folder:
   ```bash
   cd REPO-NAME
   ```
3. Open `index.html` in your browser — either double-click the file, or run it through a local server such as the VS Code "Live Server" extension for the best results.

## What I Learned

Building this project helped me get comfortable separating structure, styling, and behavior into their own files, and gave me hands-on practice rendering dynamic content onto the page using arrays, objects, and loops instead of hardcoding HTML. I also learned how small syntax mistakes (like an unclosed tag) can silently break unrelated parts of a page, which made debugging with the browser console a very important skill.
